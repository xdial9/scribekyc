# IDV Vendor Public Stack Reference

This repository contains public-source references and structured summaries for major identity verification vendors.

Scope:
- Public documentation, product materials, developer docs, and public technical references
- Public stack and capability summaries
- Public comparison across major vendors
- Internal risk synthesis based only on public evidence

This corpus does not include exploit instructions, live testing workflows, bypass guidance, or operational attack playbooks.
