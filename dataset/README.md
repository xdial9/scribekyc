## What this dataset is for

This dataset is meant to collect public, safe, non-confidential information about:

- KYC / IDV platform risk themes
- Common exploit patterns
- Public CVE categories
- Fraud and identity abuse vectors
- Standard hardening guidance

## Data sources used for this starter set

This dataset is intentionally built from broadly available public knowledge and safe public-source themes, including:

- NVD / CVE summaries
- Public security advisories
- Open documentation and security blogs
- Public KYC / IDV risk research
- General identity verification and anti-fraud guidance

## Example provider notes

This project is intentionally generalized and avoids any confidential internal or non-public competitor data.
