# Project overview and usage

This repo includes:
- a terminal-first repo assistant
- a small Flask web UI for asking questions of the local repo
- repo-grounded search and summary utilities

## Run the CLI

```bash
python assistant_cli.py chat
python assistant_cli.py overview
python assistant_cli.py ask "what is this repo about?"
```

## Run the web app

```bash
python app.py
```

Then open http://localhost:5000
